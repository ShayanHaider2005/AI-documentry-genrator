About DocuBot

DocuBot is an AI-powered documentary generator that transforms PDF lectures into narrated, scene-by-scene videos. It features:

  • PDF text extraction and sanitization
  • AI script generation using multiple LLM providers
  • Voice cloning via OmniVoice (local, zero-shot)
  • Scene-by-scene video generation with Remotion
  • Word-by-word highlighting synchronized with narration
  • Contextual visuals from document diagrams or Pexels photos

The platform offers both a web interface (npm run web) and a headless CLI (npm run pipeline) for generating documentaries from PDFs. Voice cloning runs entirely on your machine using the OmniVoice toolkit, supporting 600+ languages with accent and prosody preservation.
